# Zohir Canvas

Sketch Material 3 Expressive screens in the browser, link them, tap through them, and copy a prompt for your AI coding tool.

- Site: https://zohir630.github.io/ZohirSTEM/
- Source: https://github.com/zohir630/ZohirSTEM
- Android app: GitHub Actions tab -> "Build Android APK" -> Run workflow

Made by Zohir. Based on the MIT-licensed project M3E Canvas by lnkiai (see LICENSE and NOTICE).

## Run locally

```
npm ci
npm run dev
```
